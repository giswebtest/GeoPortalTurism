# Сесія розробки — 2026-06-02

## Зроблено за сесію

### 1. Nginx — роутинг API сервісів
- `docker/nginx.conf` — додано location блоки для GeoServer (`/geoserver/`) та PyCSW (`/csw`)
- `compose.prod.yaml` — додано сервіси `geoserver` і `pycsw`, nginx тепер `depends_on` обох
- `compose.yaml` — додано `nginx` сервіс у dev, `static_vol`/`media_vol` volumes
- `docker/nginx.conf` — `server_name` тепер включає `localhost`

### 2. Панель «Підключити дані»
- Кнопка `🔗 Підключити дані` у правому navbar
- Модальне вікно з реальними URL сервісів та кнопкою 📋 копіювати
- Сервіси: WMS, WFS, WMTS (GeoServer :8080), OGC API Features (Django :8000), CSW (PyCSW :8001)
- URL відображаються повні (абсолютні), скопіювати одним кліком

### 3. OGC API Features — виправлення для QGIS
- `maps/ogc_views.py` — додано повні URI link relations (`http://www.opengis.net/def/rel/ogc/1.0/data`)
- `maps/urls.py` — додано маршрут `/ogc` без trailing slash (301 → 200)
- Причина: QGIS не слідує 301 редиректу

### 4. Architecture.html — v2.0
- **Заголовок**: додано чіпи GeoServer 2.24, PyCSW 2.6.1, OGC API, Nginx
- **Загальна схема**: замінено лінійну схему на 4-tier клієнт-серверну архітектуру:
  - Клієнтський рівень (Browser, GIS Client, REST)
  - Мережевий рівень (Nginx reverse proxy + routing table)
  - Серверний рівень (Django, GeoServer, PyCSW, External APIs)
  - Рівень даних (PostgreSQL+PostGIS, Docker Volumes, Config)
- **API таблиця**: додано OGC API (8 endpoints), WMS/WFS/WMTS, CSW
- **Інфраструктура**: 6 контейнерів (web, db, geoserver, pycsw, nginx, certbot)
- **UML Navbar**: додано кнопку «🔗 Підключити дані» + `#connect-modal-overlay`
- **НІГД таблиця**: WMS/WFS/WMTS/CSW/UUID — «Концепція» → «✓ Реалізовано»
- **ПЗ таблиця**: додано GeoServer 2.24 та PyCSW 2.6.1
- **Footer**: v1.0 → v2.0

### 5. Cloudflare Tunnel
- Встановлено `cloudflared` через `winget`
- Запущено без акаунту: `cloudflared tunnel --url http://localhost:80`
- URL: `https://plates-predictions-alphabetical-endless.trycloudflare.com`
- `.env` — додано `.trycloudflare.com` до `DJANGO_ALLOWED_HOSTS`

## Відкриті питання

- PyCSW `unhealthy` — healthcheck перевіряє порт 8080 замість 8000 (виправлено в compose, але контейнер не перестворювався)
- GeoServer Proxy Base URL — при використанні Cloudflare/ngrok треба змінити на публічний домен
- OGC API Features в QGIS — підключення нестабільне, рекомендується WFS через GeoServer
