**Фізичне місце на Windows:**
```
\\wsl$\docker-desktop-data\data\docker\volumes\geoportalturism_postgres_data\_data
```
Це всередині WSL2 віртуального диску Docker Desktop — не звичайна папка Windows.

**Чому дані зникають після перезапуску ПК:**
Найімовірніша причина — запуск `docker compose down -v`. Прапор `-v` **видаляє volumes** разом з контейнерами. Без нього дані зберігаються.

| Команда | Що робить |
|---|---|
| `docker compose down` | Зупиняє контейнери, **дані зберігаються** |
| `docker compose down -v` | Зупиняє + **видаляє базу** |

**Щоб не втрачати дані — робіть резервну копію:**
```powershell
docker exec geoportalturism-db-1 pg_dump -U postgres geodjango1 > backup.sql
```

Відновлення:
```powershell
docker exec -i geoportalturism-db-1 psql -U postgres geodjango1 < backup.sql
```
