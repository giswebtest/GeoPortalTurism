maps
Основний геопросторовий модуль
  • Models: Location, Route, RouteLocation, Category, Region, Country, CountryPolygon, Guide, POICategory, HystoryOb
  • Views: index, hystory_ob_geojson, ivfrankdist_geojson, overpass_proxy, country_polygons_geojson, route_elevation

Адмін-панель — розширені можливості
📥 Імпорт даних
  • GeoJSON → Location (масовий імпорт)
  • GPX → Route (з геометрією)
  • GeoJSON → CountryPolygon
  • ST_Within фільтрація при імпорті
🗺️ Геометрія
  • GIS map widget у формах адміну
  • Default центр: Житомирська обл. (50.25, 28.66)
  • OSRM побудова LineString маршруту
  • Inline RouteLocation для порядку точок
⚙️ Автоматизація
  • Route.save() → ST_Length → distance_km
  • duration_min = distance × difficulty коеф.
  • Transaction-safe імпорти з rollback
  • Staff-only доступ до /admin/

Детальні сценарії
UC-1
🗺️ Пошук та перегляд локацій
Актор: Звичайний користувач · Публічний портал
Передумова: відкрита головна сторінка /, карта завантажена
  1. 1
    Користувач бачить маркери локацій на 2D карті (Leaflet)
  2. 2
    Натискає кнопку категорії (.cat-filter-btn) — фільтр у сайдбарі та на карті
  3. 3
    Клікає на маркер або картку локації у сайдбарі
  4. 4
    З'являється попап з фото, назвою, категорією, регіоном
  5. 5
    Може натиснути 🔍 для відкриття джерела інформації у новій вкладці
  6. 6
    Перемикає базовий шар (OSM / Topo / HOT / Satellite) через Layer Control
✅ Локацію знайдено, детальна інформація відображена на карті
UC-2
🛣️ Побудова маршруту та навігація
Актор: Звичайний користувач · Публічний портал
Передумова: знайдено 2+ локацій, які користувач хоче відвідати
  1. 1
    Натискає ➕ До маршруту на картці локації або в попапі
  2. 2
    Повторює для N точок — waypoints додаються в #route-nav-panel
  3. 3
    Натискає 🗺️ Побудувати маршрут → Leaflet Routing Machine → OSRM
  4. 4
    На карті відображається лінія маршруту + дистанція/час
  5. 5
    Натискає 📍 Google Maps або 🚙 Waze — відкривається deeplink
  6. 6
    Для скасування — Очистити точки видаляє всі waypoints
✅ Маршрут побудований, користувач перейшов до навігатора

Висновок

У рамках магістерської роботи розроблено та впроваджено геоінформаційний веб-портал туристичних ресурсів Івано-Франківської області — повнофункціональну програмну систему для візуалізації, пошуку та маршрутизації туристичних об'єктів на основі відкритих геопросторових технологій. Система побудована на принципах сучасної геовебархітектури і відповідає вимогам до програмних вузлів Національної інфраструктури геопросторових даних (НІГД) України.

Актуальність роботи обумовлена відсутністю єдиного цифрового інструменту, який би інтегрував туристичну інформацію регіону, маршрутизацію, геопросторовий аналіз і сервіси планування поїздок в єдиному веб-застосунку з відкритим кодом, придатному до розгортання органами місцевого самоврядування без комерційних ліцензій на ГІС-програмне забезпечення.

Основні результати роботи
1
Розроблено архітектуру геовебсистеми на стеку Django 5 + GeoDjango + PostgreSQL 16 / PostGIS 3.4, що забезпечує зберігання просторових даних (PointField, LineStringField, MultiPolygonField) у координатній системі WGS-84 (SRID 4326) та виконання геопросторових запитів засобами PostGIS (ST_Length, ST_Within, ST_AsGeoJSON). — Dockerfile: python:3.12-slim + gdal-bin + libproj-dev
2
Реалізовано дуальний картографічний рушій 2D/3D: Leaflet.js 1.9.4 для двовимірної карти з підтримкою чотирьох базових тайлових шарів (OSM Standard, OpenTopoMap, HOT Humanitarian, ESRI Satellite) та MapLibre GL 4 для WebGL-тривимірної візуалізації з можливістю нахилу та обертання. Синхронізація позиції, масштабу та маркерів між 2D та 3D режимами реалізована без зовнішніх залежностей.
3
Реалізовано RESTful GeoJSON API на основі Django Views для публікації геопросторових даних: локацій (PointField), маршрутів (LineStringField), полігонів адміністративних одиниць (MultiPolygonField), культурних пам'яток (legacy-таблиця hystory_ob — 62 об'єкти) та районів Івано-Франківської області (ivfrankdist). Усі ендпоінти повертають формат GeoJSON FeatureCollection.
4
Інтегровано систему побудови маршрутів на основі OSRM (Open Source Routing Machine) через Leaflet Routing Machine: додавання довільних waypoints з бібліотеки локацій, автоматична побудова оптимального маршруту, відображення відстані та часу. Маршрути експортуються до Google Maps та Waze через deeplink-інтеграцію для мобільної навігації.
5
Розроблено модуль профілю висот із синхронізованою візуалізацією: серверний endpoint /api/routes/<id>/elevation/ отримує висоти точок маршруту з OpenTopoData API (SRTM90m), обчислює відстані за формулою Гаверсинуса, Chart.js 4.4.3 відображає інтерактивний лінійний графік з кастомним crosshairPlugin — позиція курсора на графіку синхронізується з маркером на карті в режимі реального часу.
6
Реалізовано проксі-інтеграцію з Overpass API (OpenStreetMap) для динамічного завантаження POI (об'єктів інтересу): ресторани, готелі, банкомати, парковки, медичні заклади. Конвертація відповіді Overpass у GeoJSON здійснюється засобами osmtogeojson 3.0 на стороні клієнта. POI відображаються шаром Leaflet з можливістю додавання до маршруту.
7
Реалізовано розширену адміністративну панель на Django Admin з підтримкою GIS-віджетів для редагування геометрій, масового імпорту локацій з GeoJSON, імпорту маршрутів з GPX-файлів, побудови геометрії маршрутів через OSRM API, упорядкованих waypoints (inline RouteLocation), авто-розрахунку дистанції та тривалості через PostGIS ST_Length.
8
Впроваджено production-готову інфраструктуру на Docker Compose: Python 3.12 + Gunicorn (3 workers) + Nginx 1.25 (reverse proxy, статика, SSL termination) + PostgreSQL/PostGIS + Certbot (Let's Encrypt TLS). Конфігурація через python-decouple (.env), ізольоване середовище для dev (runserver) та prod (gunicorn) з єдиним Dockerfile.
Практичне значення

Розроблений геопортал може бути впроваджений органами місцевого самоврядування, туристично-інформаційними центрами та закладами освіти як відкрита цифрова платформа для просування туристичного потенціалу регіону. Система не потребує комерційних ліцензій на ГІС-програмне забезпечення — увесь технологічний стек базується на відкритому програмному забезпеченні (Open Source). Інтеграція з сервісами Google Maps, Waze, Booking.com, Airbnb та Google Calendar забезпечує замкнутий цикл туристичного планування безпосередньо з веб-порталу.

Публікація на Національному геопорталі
Реєстрація CSW-каталогу PyCSW та WMS/WFS GeoServer-сервісів на Національному геопорталі України як офіційного вузла НІГД рівня органу місцевого самоврядування Івано-Франківської області.

Розроблена система GeoPortal Turism реалізує концепцію відкритого геовебпорталу регіонального рівня, що поєднує сучасні стандарти геопросторових веб-сервісів (OGC, GeoJSON, PostGIS) з практичними інструментами туристичного планування. Застосування виключно відкритого програмного забезпечення (Django, PostgreSQL, Leaflet, OSRM, OpenTopoData) забезпечує відтворюваність результатів та можливість масштабування рішення на будь-який регіон України без додаткових фінансових витрат на ліцензування. Архітектурні рішення, обрані в роботі, відповідають стратегічному напрямку розвитку геопросторової інфраструктури України та можуть слугувати типовим зразком програмного вузла НІГД рівня органу місцевого самоврядування.
